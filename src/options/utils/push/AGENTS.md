# 推送模块约定

- 自动通知仅使用设置中选定且启用的渠道；手动测试使用当前输入，可独立于自动推送开关。旧配置没有 `pushProvider` 时仍按 IYUU 处理。
- 接口成功必须同时满足 HTTP 成功和渠道业务成功码；请求及响应读取都需要超时。失败返回结果，不影响已保存的签到记录，不自动重发，以免重复通知。
- Telegram 使用纯文本，长报告按 4096 字符以内分段且保持完整 Unicode 字符。错误提示隐藏令牌，不记录含令牌的 URL 或原始网络异常。
- 请求逻辑保持无浏览器存储依赖，使用 `test/push-notice.test.js` 的模拟请求验证错误、超时、分段和兼容行为；运行 `npm test` 及 `npm run build`。实际送达需单独配置并测试。
