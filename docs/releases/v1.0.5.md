# v1.0.5

## 安全验证超时默认关闭签到页

新增「其他设置 → 标签页设置 → 验证超时后保留页面」，升级后默认关闭。

- **关闭**：安全验证等待 60 秒仍未通过时，记录超时并关闭该签到页，本轮不自动重试。
- **开启**：超时后保留该签到页，供手动验证。

签到调试模式仍会保留页面。已打开的旧签到窗口需手动关闭。

## 更新方式

下载 `pt-auto-sign-1.0.5-chrome.zip`，解压并覆盖原扩展目录，再在 Chrome/Edge 扩展管理页点击「重新加载」。不要先卸载，以免丢失原有配置和签到记录。

已完成 Chrome 生产构建和清单校验；远程浏览器遇到验证超时后的实际关页行为尚未验收。
