# v1.0.4

## 更新内容

- 新增猪猪 `PIGGO` 独立签到策略，适配日历页面；只领取今日奖励，不触发补签或消耗补签卡。
- 适配 Rousi 新版首页快捷签到，领取固定奖励，以“已签到 N 天”确认成功。
- 修复 TTG 点击后过早返回的问题，等待异步签到回执，并防止同一页面重复提交。
- 新增 Telegram 推送渠道，支持配置、手动测试、长汇总分段和错误提示；保留 IYUU。
- 新增“导出 PT Cookies”，按已配置站点生成本地 JSON 文件，首次使用时申请 Cookie 权限。
- 合入远端已有的签到状态判定、重试和安全验证修复；无法确认的结果保留页面供人工处理，首页备注按当天记录显示。

## 升级与配置

下载 `pt-auto-sign-1.0.4-chrome.zip` 并解压。Chrome/Edge 的开发者模式用户可覆盖原扩展目录，再在扩展管理页点击“重新加载”；不要先卸载，以免丢失原有配置和记录。本次为 GitHub 发布包，未提交浏览器扩展商店审核。

- 猪猪：编辑已有站点，保留原名称，将类型改为 `PIGGO`，地址改为 `https://piggo.me/calendar`；新增站点也可选择“猪猪”预设。
- Rousi：类型继续使用 `ROUSI`，地址为 `https://rousi.pro/`。
- Telegram：在“其他设置 → 消息推送”选择渠道并配置。先点击“测试推送”，在目标会话确认收到后，再启用自动推送。
- Cookies：入口位于“站点设置 → 导出 PT Cookies”。文件包含登录凭据，只交给可信工具导入，不要公开或提交到代码仓库。
